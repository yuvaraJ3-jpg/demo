Copy the owner's photos into this folder and use these exact file names
(lower case, .jpg). No HTML change is necessary.

Photo tips
----------
- Recommended size: about 1200 x 900 pixels (4:3). Keep each file under 300 KB.
- The site crops photos with CSS object-fit, so keep the subject in the centre.
- Use clean product photos for product cards. Do not use the same shop photo
  for every product.
- Do not edit brand names or logos on product packaging. A brand name in a
  photo does not mean that the shop is an authorised dealer.
- Uploaded photos are NOT copied to the website automatically. You must put
  them in this folder before you upload the website to the host.
