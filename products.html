Before you order

Four details that make ordering easier

Measure the area

Measure each room in square feet or metres. Add 5–10% extra tiles for cutting and breakage.

Buy from one batch

Tile shades can change between batches. Buy all tiles for one area in a single order.

Note the product code

Write down the brand, product code, size and finish, or send a clear photo of the item.

Share site details

Tell us the delivery location, floor level and access for unloading, if you need delivery.
